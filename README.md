 مشروع مطعم "Tasty Food Restaurant"

 فكرة المشروع
مشروع موقع إلكتروني تفاعلي صُمم خصيصاً لمطعم "Tasty Food". يهدف الموقع إلى عرض قائمة الطعام (Menu) بطريقة جذابة، توضيح الخدمات المقدمة، وتوفير تجربة مستخدم سلسة وتفاعلية عبر واجهات الموقع. تم التركيز في هذا المشروع على التصميم المتجاوب وسهولة التصفح.

 الأدوات والتقنيات المستخدمة
- HTML5: لبناء هيكلية الموقع الأساسية.
- CSS3:  لتصميم وتنسيق واجهات الموقع وإضافة اللمسات الجمالية.
- JavaScript: لإضافة التفاعل للموقع وتحسين تجربة المستخدم.
- GitHub:  لإدارة إصدارات المشروع والتعاون بين أعضاء الفريق.
